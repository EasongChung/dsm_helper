## 3. Gate/proof rules

Every RED/GREEN step checks requested payload and **business behavior**, not just source string presence. Fake adapters and widget tests are sufficient for protocol-shape and UI decision tests, not for DSM conflict/file mutation claims. Real-device operations require a separately created disposable DSM test directory with unique test files, explicit destructive confirmation and documented outcomes. A skipped test is `NOT TESTED`, not `PASS`.

To close Task 7B: all enabled operation contracts pass targeted and full CI, analyzer, stable-signature Debug APK; user confirms real DSM behavior for the **enabled** mutation operations; actual `feature/t7b-file-operations` diff/HEAD/CI verified; no 7C functionality or primary Files cutover. `T7B-GAP-01` is an explicit **blocker to enabling B5 CopyMove** until it is resolved; do not silently waive it just to declare the whole feature complete.
